# Human Reversal Lab

차트에서 **직접 클릭한 변곡 구간**을 정답으로 만드는 로컬 연구 앱입니다. 조건을 임의로 최적화하기보다, 사람이 보는 저점·고점 패턴을 과거 100봉에서 학습합니다. 원래의 정적 거래 사례 차트는 `index.html`에 있습니다.

## 실행

Python 3.11 이상이 필요합니다. 권장 버전은 3.12입니다.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lab.txt
python -m reversal_lab import BTCUSDT_15m.csv --name 'BTCUSDT 15m'
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m reversal_lab serve
```

브라우저에서 **http://127.0.0.1:8765** 를 엽니다. CSV 가져오기는 웹 화면에서도 가능합니다. 최초 CSV를 가져오기 전에는 캔들이 없습니다.

CSV는 `timestamp,open,high,low,close,volume` 형식입니다. `timestamp`는 UTC epoch 밀리초·초 또는 ISO 날짜이며 `open_time/time/datetime/date` 별칭도 지원합니다. 시간은 15분봉 **시작 시각**입니다. UI는 한국시간으로 표시합니다. 거래량이 없으면 결측으로 처리합니다. OHLC 오류, 중복 시각, 15분봉이 아닌 간격은 거절합니다. 시간 간격이 빈 구간은 저장할 수 있지만, 학습과 추론에서 이를 가로지르는 100봉은 제외합니다. **완성된 캔들만 가져오세요.**

## 사용 순서

1. 차트를 드래그·확대하거나 한국시간 날짜로 이동합니다.
2. **저점 / 롱**, **고점 / 숏** 모드를 선택하고 실제 변곡 캔들을 클릭합니다. 반경 ±0~5봉으로 애매한 구간도 표시할 수 있습니다. 같은 캔들을 다시 누르면 수정됩니다. 삭제·직전 변경 취소를 지원합니다.
3. 충분히 확인한 뒤 **현재 보이는 구간 검토 완료**를 누릅니다. 이 구간 안에서 라벨이 없는 미래 구간만 중립 정답으로 사용합니다. **검토하지 않은 구간을 자동으로 음성 샘플로 만들지 않습니다.** 검토 범위를 해제할 수도 있습니다.
4. 서로 떨어진 여러 날짜에서 저점·고점과 그 밖의 구간을 수집합니다. 앞·중간·뒤 기간에 두 종류의 라벨이 모두 있어야 합니다. 학습 구간의 독립 저점/고점 각 3개 이상, 검증/테스트 각 1개 이상이 최소 기능 조건입니다. 이 적은 수로 실제 정확도를 입증할 수는 없습니다. 실전 평가에는 훨씬 다양한 구간이 필요합니다.
5. **새 모델 학습**을 누릅니다. 학습은 백그라운드에서 실행되며 상태와 오류가 화면에 표시됩니다.
6. **테스트 구간 보기 → 현재 구간 예측**을 누릅니다. 사람 라벨은 실제 변곡 위치에, AI는 **판단이 나온 봉**에 표시합니다. 신호를 미래 변곡 위치에 소급 표시하지 않습니다.
7. 라벨을 바꿨다면 모델이 `이전 라벨`로 표시됩니다. 변경 사항을 반영하려면 다시 학습하세요.

`라벨 백업`은 데이터 지문·라벨·검토 구간을 JSON으로 내보냅니다. `라벨 병합`은 같은 캔들 데이터에만 허용하며 기존 라벨을 덮어쓰거나 추가하되, 백업에 없는 라벨을 지우지는 않습니다. 잘못된 백업은 전체를 취소하며 부분 저장하지 않습니다. 다른 탭에서 수정한 라벨을 오래된 화면이 덮어쓰지 않도록 버전 충돌을 검사합니다.

## 새 캔들에서 기존 모델 사용

`새 봉 이어 붙이기`에서 **기존 전체 OHLCV + 새로운 완성봉**의 CSV를 선택하세요. 기존 부분이 한 값이라도 다르면 거절합니다. 일치하면 원본을 보존한 새 데이터 버전을 만들고 라벨·검토 구간과 기존 모델을 연결합니다. 추가 구간은 미검토 상태이므로 자동으로 중립 학습 정답이 되지 않지만, 기존 모델로 미래 예측은 바로 확인할 수 있습니다. 새 라벨을 모은 뒤 다시 학습할 수도 있습니다. 과거 가격이 정정된 CSV는 별도 데이터로 가져와야 합니다.

학습한 저점/고점과 중립 구간의 특징 중앙값 차이는 모델 상세의 `라벨 구간에서 관찰한 패턴`에서 확인할 수 있습니다. 이 분석도 학습 부분에만 근거하며 인과관계나 수익성을 뜻하지 않습니다.

## 무엇을 예측하는가

기본값은 **봉 t가 완성된 시점까지의 100봉으로, 다음 3봉 안에 사람이 표시한 저점/고점 구간이 오는지**를 분류하는 것입니다. 예측 범위는 1~12봉으로 바꿀 수 있습니다. 미래 가격은 특징에 들어가지 않습니다. 다음과 같이 목표를 만듭니다.

- 클릭 구간이 `[pivot-radius, pivot+radius]`이면, 미래 예측 범위가 이 구간과 겹치는 판단 봉을 저점/고점 정답으로 만듭니다.
- 그 미래 범위 전체가 직접 검토된 경우만 학습에 씁니다.
- 같은 미래 범위에 저점과 고점이 모두 있으면 애매한 샘플로 제외합니다.
- 겹치거나 가까운 클릭은 하나의 독립 사건으로 묶습니다. 클릭 수만 늘려 표본을 부풀리지 않습니다.

특징은 극값 위치·거리, 꼬리·몸통·종가 위치, 1~99봉 가격 변화, 이동평균 기울기, 과거 캔들 비율, 유한 구간 변동성·Cutler RSI, 거래량 변화 등입니다. 모든 특징은 **유한한 과거 100봉 안**에서 계산됩니다. 화면의 BB50은 참고 표시이며 모델의 진입 규칙이 아닙니다.

## 학습·평가의 누수 방지

- 검토된 샘플을 시간순으로 약 60/20/20%로 나눕니다. 무작위 분할하지 않습니다.
- 라벨 반경과 미래 예측 범위를 경계에서 제외하고, 검증·테스트 시작에 100봉의 간격을 둬 입력 구간 중복도 제거합니다.
- 같은 클릭 사건이 서로 다른 분할에 들어가면 학습을 거절합니다.
- 결측 처리·스케일러·모델은 학습 구간에만 적합합니다. Logistic Regression과 Gradient Boosting 및 점수 기준은 검증 구간에서만 선택합니다. 테스트 정답은 마지막 평가에만 사용합니다.
- 저장된 모델은 학습 부분으로만 훈련된 바로 그 모델입니다. 테스트까지 넣어 다시 학습한 모델을 같은 테스트 성능이라고 표시하지 않습니다.
- 과거로 소급한 신호를 막기 위해, 차트 예측 API는 해당 모델의 테스트 시작 시각 이후만 표시합니다.

**정밀도·재현율·F1은 사람 라벨과의 일치도이며, 매매 승률·수익률이 아닙니다.** TP/SL 백테스트를 임의로 섞지 않았습니다. 실제 사용자 라벨이 쌓이기 전에는 사용자 전략의 성능을 주장할 수 없습니다.

## 저장·재현

기본 `.labeler-data/`에 SQLite와 모델을 저장합니다. `--data-dir PATH` 또는 `REVERSAL_DATA_DIR`로 바꿀 수 있습니다. 데이터와 모델은 Git에서 제외됩니다. 소스만 공개 저장소에 올라갑니다.

각 모델은 특징 버전, 데이터 SHA256, 라벨 버전·스냅샷 SHA256, 실제 라벨 스냅샷, 예측 범위, 시간순 분할 시각, 검증/테스트 지표, 비교한 모델 설정과 실행 라이브러리·소스 지문도 저장합니다. 사용자 수정 중에도 진행 중인 학습의 라벨 스냅샷은 바뀌지 않습니다. 재시작 때 미완료 작업은 실패로 표시합니다.

단일 사용자 로컬 앱입니다. 외부 접속이 필요한 신뢰된 환경에서는 `serve --host 0.0.0.0`을 사용할 수 있습니다. 공개 인터넷에는 인증된 프록시 없이 노출하지 마세요. 쓰기 API는 세션 CSRF·동일 출처 검사, 매개변수 검증, 원자적 저장을 사용하며 외부 모델 파일을 역직렬화하는 업로드 API는 없습니다.

기존 정적 `index.html`과 달리 이 앱은 Python API가 필요합니다. **GitHub Pages만으로 학습·SQLite 저장이 실행되지는 않습니다.**

## 테스트

```bash
python -m pip install -r requirements-dev.txt
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m unittest discover -s tests -t . -v
python -m playwright install chromium
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m tests.browser_e2e
```

`CHROMIUM_PATH`로 설치된 Chromium 경로를 지정할 수 있습니다. 브라우저 테스트는 격리된 임시 DB와 **합성 데이터**로 서버를 띄우고 다음을 검증합니다.

- 클릭·수정·취소·삭제·새로고침 후 저장 유지
- 검토 범위·백업 다운로드
- 비동기 학습 완료·미사용 테스트 구간 예측·모바일 레이아웃

단위/API 테스트는 데이터 검증, 미래 가격 변경에 대한 특징 불변성, 정확한 100봉 문맥, 미검토 음성 제외, 예측 범위, 라벨 충돌, 버전 충돌, 원자적 백업 병합, 시간순 분할·사건 격리, 모델 저장·오래된 모델 감지, 새 데이터의 이력 대조·모델 재사용, API 보안을 검사합니다. 합성 테스트의 지표를 실제 시장 성능으로 해석하지 마세요. `.test-artifacts/`에는 브라우저 스크린샷이 생성되며 Git에는 포함하지 않습니다. GitHub Actions에도 같은 검사 흐름을 추가했습니다.
