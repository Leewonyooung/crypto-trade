# 모든 시간봉용 Pine 지표

`Vol50_MidHalf_AllTimeframes.pine`을 TradingView Pine Editor에 붙여 넣으세요. 현재 차트의 OHLCV를 그대로 사용하며 다른 시간봉으로 강제 변환하지 않습니다.

- 최근50봉 거래량 최대 발생 후 다음 봉부터 탐색, 최초 발생부터 실제 진입까지 최대10 **차트 봉**. 진행 중 발생은 대기를 연장하지 않습니다.
- 롱: 100봉 저점 부근의 아래꼬리40% 이상 + 양봉/도지. 숏은 고점·윗꼬리·음봉으로 대칭.
- SL은 신호봉 포함 최근5봉 저가/고가. 다음 관측 봉 시가 체결, 세션 휴장 갭은 시가/손절 조건으로 처리합니다.
- 가격2R TP보다 BB50중단을 먼저 터치하면50% 익절. 나머지는 기존 SL/2R 유지. 거래별 독립, 양방향 동시 보유.
- 탐색 기한의 고정15분/150분 계산을 제거했습니다. 5분봉이면10개5분봉,1시간이면10개1시간봉,일봉이면10개일봉입니다. 시작일 기본값도 전체 이력으로 바꿨습니다.

기존 모델은15분봉 학습 결과입니다. ML은 기본OFF이며 켜도 **15분봉에서만** 적용합니다. 다른 시간봉은 캔들 규칙으로 작동하고 오른쪽 위에 모드를 표시합니다. 이 변경은 다른 시간봉의 ML 재학습/수익성 검증을 뜻하지 않습니다. ML 사용 시2026년 이후/500봉 문맥, 일반 규칙은 최소100봉(거래량 길이를 늘리면 그 이상)이 필요합니다.

모든 시간봉에서 해당 길이만큼의 OHLCV가 필요합니다. 특히 월봉·연봉처럼 봉 수가 부족하면 신호를 만들 수 없습니다. 종목에 거래량 데이터가 없으면 거래량 피크도 감지할 수 없습니다.

반익 표시는 확정OHLC 시뮬레이션입니다. 실제 틱 자동주문 실행기가 아닙니다. 같은 봉에서 SL과 익절이 모두 닿으면 보수적으로SL우선, 시가 갭 이벤트는 먼저 처리합니다. TradingView 실제 컴파일·실행은 미검증입니다.
